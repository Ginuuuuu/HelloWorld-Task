nodemon => changes finder and restart automatically

npm install -g nodemon ('-g' shows globally install)



lodash => necessary functions are available

npm i -g npm || npm i -save lodash



cokkie-parser => structure the cookie in json format

npm i cookie-parser



express-session => handle & manage sessions

npm i express-session



passport for third-party authentifucations && passport-local for username password authentification

npm i passport passport-local




dotenv is used to access the env files

npm i dotenv
