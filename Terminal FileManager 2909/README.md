## COMMANDS

### <help> command will list all the comands
```text
help
```
### <ls> will list the dir and files
```text
ls
```
### <cd> will open dir
```text
cd <path>
```
### <pwd> will dispaly working dir
```text
pwd
```
### <mkdir> will create dir
```text
mkdir <name>
```
### <touch> will create file
```text
touch <name>
```
### <rename> will rename the file/dir
```text
rename <source> <destination>
```
### <copy> will copy the file from the give path to working path
```text
copy <source> <destination>
```
### <move> will move the file
```text
move <source> <destination>
```
### <delete> will delete the file/dir
```text
delete <path>
```
### <cat> will open the file
```text
cat <file>
```
### <fin> the word from the give file
```text
find <path> [--name=...] [--ext=.js] [--case-sensitive]
```
### <info> is used to inspect the details/metadata of a file or directory
```text
info <path>
```
### <tree> will show the repo structure
```text
tree [path] [--depth=N]
```
### <clear> will clear the terminal
```text
clear
```
### <history> will show the past ran commands
```text
history
```
### <undo> | <redo> will reverse and restore file-manager operations, similar to Ctrl + Z and Ctrl + Y in many applications
```text
undo
redo
```
### <exit> will exit the terminal file managerrrr
```text
exit
```
